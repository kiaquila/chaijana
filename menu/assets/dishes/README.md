# Dish image hooks

The build knows these optional filenames. Existing files are rendered; absent files are omitted without a broken-image placeholder. Run `npm run build` after adding an image.

- `chaijana-experiences.webp`
- `draniki-salmon.webp`
- `crispy-eggplant.webp`
- `adjarian-khachapuri.webp`
- `suyru-lagman.webp`
- `lula-kebab.webp`
- `uzbek-plov.webp`
- `manti.webp`
- `kids-menu.webp`
- `medovik.webp`
- `uzbek-tea.webp`
- `fruit-shakes.webp`
- `cocktails.webp`
- `wine.webp`
- `hookah.webp`

Use the restaurant's exact dish photographs (or identical dishes with explicit approval), preserve transparent masks when present, export as WebP, and aim to keep each file below 250 KB.
